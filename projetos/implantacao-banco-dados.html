Implantação de Banco de Dados

Criação de um Diagrama Entidade Relacionamento e implantação de um banco de dados relacional em SQL.

Categoria
Projeto acadêmico
Ano
2026
Área
Banco de dados relacional

Objetivo

Modelar e implementar uma base de dados relacional capaz de organizar informações de uma empresa com consistência e clareza.

Descrição detalhada

Esta página pode apresentar o contexto do banco de dados, as entidades principais, os relacionamentos definidos e as regras de negócio consideradas na modelagem.

Também é um bom lugar para incluir decisões de normalização, scripts SQL, consultas importantes e exemplos de uso do banco.

Principais atividades

  • Modelagem conceitual do banco de dados.
  • Criação do Diagrama Entidade Relacionamento.
  • Definição de tabelas, chaves e relacionamentos.
  • Implementação usando SQL.

Tecnologias e temas

Banco de dados relacional, SQL, modelagem de dados, DER, entidades e relacionamentos.
